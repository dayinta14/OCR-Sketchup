Latar Belakang

Masalah & Solusi

Proses inspeksi struktur selama ini dilakukan manual — data di kertas/PDF tidak terhubung langsung dengan model 3D.

📋
Masalah Lama
Inspektor mengisi form manual. Hasilnya disimpan di PDF. Tim engineer harus membuka PDF satu per satu untuk tahu kondisi tiap elemen struktur.
⚡
Solusi Baru
Sistem membaca PDF secara otomatis dan langsung mewarnai model 3D SketchUp sesuai kondisi inspeksi — merah, kuning, hijau, dst.
🎯
Hasil
Engineer bisa langsung melihat kondisi seluruh struktur dari model 3D — tanpa perlu buka satu per satu form inspeksi.

Alur Otomatisasi

Cukup double-click satu file — semua proses berjalan otomatis

📄
1
Baca Form Inspeksi
run_ocr_json copy.py

→
🗺️

→
📊
3

→
🎨
4
Warnai Model 3D

Cara Pakai — 3 Langkah

Setiap kali ada form inspeksi baru, cukup ikuti 3 langkah ini

1
Taruh PDF baru di folder, lalu double-click reset_dan_run.bat
→ Otomatis baca PDF + simpan hasil ke JSON
🖱️
2
Buka SketchUp → Extensions → Ruby Console
load "...path.../update_colors_from_ocr.rb"
💻
3
Model 3D otomatis diwarnai sesuai kondisi inspeksi
View → Face Style → Shaded with Textures jika warna belum muncul
